# ZeroNet-2B-MoE

[Read in English](README.md)

ZeroNet-2B-MoE — модель на основе смеси экспертов (MoE), которая принимает число и предсказывает `zero` (ноль) или `nonzero` (ненулевое). У модели **2 000 000 000 обучаемых параметров**. Текущая точность на синтетической тестовой выборке — **около 70%**.

## Быстрый запуск

Понадобится Python 3.11. Выполните команды из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Положите файл `ZeroNet-2B-MoE-v0.1.0-int8.zip` (1,86 ГиБ) из релиза в корень репозитория. Модель загружается прямо из ZIP.

```powershell
.\.venv\Scripts\python.exe -m zero_moe predict --weights ZeroNet-2B-MoE-v0.1.0-int8.zip --seed 7 -- 0 12 -12 0.05
.\.venv\Scripts\python.exe -m zero_moe evaluate --weights ZeroNet-2B-MoE-v0.1.0-int8.zip
```

В Linux или macOS используйте `.venv/bin/python`. Команда предсказания выводит одну метку на число. Пример выводит `zero`, `nonzero`, `nonzero`, `zero`.

## Обучение из исходного кода

Полные веса после обучения занимают около 4 ГБ в формате FP16. Команда `pack` упаковывает их в формат релиза INT8.

```powershell
.\.venv\Scripts\python.exe -m zero_moe train --minutes 30
.\.venv\Scripts\python.exe -m zero_moe evaluate
.\.venv\Scripts\python.exe -m zero_moe pack --output ZeroNet-2B-MoE-v0.1.0-int8.zip
```

Для быстрой пробы добавьте `--experts 2 --weights weights-demo` к команде обучения. Передайте тот же `--weights weights-demo` при оценке и предсказании. Обучение создаёт новую папку и записывает манифест, когда готовы все запрошенные эксперты. Для повторного прогона выберите новую папку.

## Модель и тестовые данные

- Модель состоит из 1 000 независимо инициализированных нейросетей. У каждой 2 000 000 весов и смещений и слои размером 3 → 547 → 3 639 → 1. Маршрутизатор равновероятно выбирает одного эксперта на число. Параметр `--seed` позволяет воспроизводить маршруты.
- Обучение использует SGD в FP32 на CPU и обрабатывает по одному эксперту за раз. Веса сохраняются в FP16. Для предсказания с диска загружается выбранный эксперт. По умолчанию каждый эксперт проходит 64 шага по 64 примера. Git игнорирует файлы весов.
- Вход имитирует датчик с шагом округления 0,25. В тестовой выборке ожидается 50% точных нулей, 30% малых ненулевых чисел с модулем 0,005–0,12 и 20% ненулевых чисел с модулем 1–16. После округления малое ненулевое число может иметь те же входные признаки, что и ноль.
- Оценка использует отдельные случайные последовательности и по умолчанию проверяет каждого сохранённого эксперта на 256 примерах. В JSON-отчёте строки матрицы ошибок соответствуют истинным меткам, столбцы — предсказанным. Порядок меток — `zero`, `nonzero`.

Обученные веса FP16 и файл релиза INT8 дали **69,97%** на одной и той же тестовой выборке из 256 000 примеров (по 179 121 верному ответу). [Результаты замеров](benchmarks/baseline.json)

Команда для запуска тестов — `python -m unittest discover -s tests -v`.

## Частые вопросы

**В: Почему бы просто не использовать `x == 0`?**

**О:** ZeroNet-2B использует силу искусственного интеллекта.

**Нужна ли видеокарта?**

Обучение и предсказание выполняются на CPU.

**Сколько параметров используется для одного предсказания?**

Маршрутизатор выбирает одного из 1 000 экспертов на каждое число. Выбранный эксперт использует 2 млн параметров.

**Как текущая модель обрабатывает числа, близкие к нулю?**

Перед предсказанием вход округляется. Малое ненулевое число, например `0.05`, может попасть в тот же интервал округления, что и ноль, и получить метку `zero`.

**Как получить обученные веса?**

Для предсказания и оценки используйте ZIP из релиза. Чтобы получить веса самостоятельно, запустите `python -m zero_moe train` из корня репозитория.
